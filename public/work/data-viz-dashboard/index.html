Interactive COVID-19 Dashboard

A real-time dashboard tracking vaccination rates and case trends by county.

October 20, 2025
D3.jsJavaScriptData Visualization

Project

Built an interactive, map-based dashboard that visualized COVID-19 vaccination rates, case counts, and demographic breakdowns at the county level across all 50 states. The dashboard updated daily from CDC and state health department APIs.

Technical Details

  • Frontend built with D3.js and vanilla JavaScript
  • Choropleth maps with drill-down from state to county level
  • Time-series charts with adjustable date ranges
  • Data pipeline in Python pulling from multiple public APIs

Impact

The dashboard was featured in the university’s data science showcase and used by the campus health office to communicate vaccination trends to students and staff.
