Monte Carlo Methods for Option Pricing

Implementing and comparing variance reduction techniques for pricing exotic options.

November 18, 2025
PythonFinanceSimulation

Project

Implemented several Monte Carlo simulation techniques for pricing path-dependent options (Asian, barrier, and lookback options) and compared variance reduction strategies.

Methods Compared

  • Naive Monte Carlo
  • Antithetic variates
  • Control variates (using Black-Scholes as control)
  • Importance sampling
  • Stratified sampling

Key Results

Control variates using the geometric Asian option as a control reduced variance by 95% compared to naive simulation for arithmetic Asian option pricing. Antithetic variates provided consistent 30-50% variance reduction across all option types with minimal implementation overhead.

Tools

Python with NumPy for simulation, Matplotlib for convergence plots, and a custom options pricing library built during the project.
