Predictive Modeling for Urban Transit

Built a machine learning pipeline to forecast subway ridership across NYC stations.

January 15, 2026
PythonMachine LearningTransit

Overview

This project developed a predictive model for NYC subway ridership using historical turnstile data, weather patterns, and event schedules. The goal was to help the MTA optimize staffing and train frequency during peak and off-peak hours.

Approach

We collected three years of turnstile data from the MTA’s open data portal and merged it with NOAA weather records and a calendar of major city events. After extensive feature engineering, we trained and compared several models including XGBoost, LSTM networks, and a traditional ARIMA baseline.

Results

The final XGBoost ensemble achieved a MAPE of 4.2% on held-out test data, outperforming the ARIMA baseline by 38%. The model was deployed as a REST API for internal use.

Key Takeaways

  • Feature engineering (especially time-based cyclical features) mattered more than model complexity
  • Weather had a surprisingly small effect except during extreme events
  • Station-level models outperformed a single global model
