Bayesian Networks for Medical Diagnosis

Course project modeling symptom-disease relationships using probabilistic graphical models.

December 5, 2024
PythonBayesianHealthcare

Overview

For the graduate probabilistic models course, I implemented a Bayesian network to model the relationships between symptoms, risk factors, and diseases in a simplified medical diagnosis setting.

Approach

  • Constructed a directed acyclic graph encoding conditional dependencies
  • Implemented exact inference using variable elimination
  • Compared against approximate inference via Gibbs sampling
  • Evaluated diagnostic accuracy on a synthetic patient dataset

Results

The Bayesian network achieved 89% diagnostic accuracy on the test set, with particularly strong performance on cases involving multiple co-occurring conditions where simpler classifiers struggled.
