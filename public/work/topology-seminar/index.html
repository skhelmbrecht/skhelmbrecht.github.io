Topological Data Analysis Seminar Paper

Exploring persistent homology as a tool for shape recognition in noisy point cloud data.

February 14, 2025
MathematicsTDAResearch

Summary

This paper, written for the graduate topology seminar, surveys the use of persistent homology in topological data analysis (TDA). It focuses on how TDA techniques can extract meaningful topological features from noisy, high-dimensional point cloud data.

Contents

  1. Background on simplicial complexes and homology
  2. Construction of Vietoris-Rips and Čech complexes
  3. Persistence diagrams and barcodes
  4. Stability theorems and noise robustness
  5. Application: classifying 3D shapes from the ModelNet dataset

Conclusion

Persistent homology provides a principled, coordinate-free approach to understanding the “shape” of data. While computational costs remain a barrier for very large datasets, recent algorithmic advances make TDA increasingly practical for real-world applications.
